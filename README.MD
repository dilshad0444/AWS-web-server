AWS Web Server Deployment

Project Overview

This project demonstrates deploying a web server using Amazon EC2.

AWS Services Used

* Amazon EC2
* Amazon VPC
* Security Groups

Project Steps

1. Created an EC2 instance using the AWS Management Console.
2. Configured the network settings.
3. Configured security group rules.
4. Tested the web server.

Skills Practiced

* AWS EC2
* Linux fundamentals
* Networking
* Security groups

Project Outcome

This project helped me understand how to deploy and configure a web server using AWS.
